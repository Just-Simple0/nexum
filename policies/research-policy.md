# Research Policy

Do not rely on model memory for current external behavior.

| Question type | Route |
| --- | --- |
| Library, SDK, framework, or API behavior | `docs-guide` first; verify the project version and use matching official documentation |
| Simple current public information | Normal web search/fetch |
| Public-page retrieval failure | `insane-search` as retrieval fallback |
| Architecture comparison, security investigation, conflicting evidence, or broad technology choice | `insane-research` |

For software claims, rank evidence as: version-matched official docs; official specification/source/release notes; maintainer discussions; trusted technical sources; community reports. Re-check important software/API claims from deep research against official documentation when possible.

Record source, claim, confidence, and unresolved uncertainty. If credible sources conflict, report the conflict and its authority rather than silently choosing.
